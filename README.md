# TabTab - 标签页会话管理器

> 一键保存、命名、恢复你的浏览器标签页组合，告别标签页焦虑。

---

## 功能特性

### v1.6.0
- **标签页布局切换** — 大框页面详情区右侧新增三种布局切换按钮，偏好自动保存到本地：
  - 🔲 **平铺（Grid）**：默认，自适应多列卡片，标题 + URL + 图标
  - ⊞ **紧凑（Compact）**：更密集的多列展示，隐藏 URL 节省空间，适合标签页多的会话
  - ☰ **列表（List）**：单列全宽行，标题和 URL 在同一行，快速浏览

### v1.5.0
- **完整语言切换** — 切换中/英文后，所有界面文字即时更新：Header 统计、侧边栏标题、详情区按钮、空状态提示、弹窗内容等全面覆盖，两个页面均同步生效
- **全页内嵌保存面板** — 大框页面点击「保存标签页」不再弹出小窗，而是在右侧主内容区直接展开操作面板（输入名称、勾选标签页、确认保存），体验完全融入大框页面
- **会话标签页管理** — 每个标签页卡片右侧新增 ✕ 删除按钮，可单独从会话中移除；详情区新增「+ 添加标签页」按钮，弹出当前窗口中尚未加入本会话的标签页供选择添加

### v1.4.0
- **展开/收起图标** — 小窗展开按钮改为斜尖头箭头（macOS 全屏风格）；全页右上角新增对称收起箭头，点击关闭当前标签页
- **全页设置面板** — ⚙️ 图标打开设置弹窗，包含主题切换、自定义背景（颜色+图片+透明度）、语言切换，与小窗设置完全一致
- **全页保存标签页** — 「保存标签页」按钮弹出选择面板，读取当前窗口所有标签页（自动排除扩展页本身），支持命名、全选/单选，保存后立即在左侧栏显示

### v1.3.0
- **语言切换** — 设置面板新增语言选项，支持 🇨🇳 中文 / 🇺🇸 English，切换后所有界面文字即时更新并持久化
- **导入增强** — 导入弹窗新增「从本地文件导入」，支持读取由「导出」生成的 `.json` 备份文件，自动恢复全部会话；同时保留分享码粘贴方式
- **全页管理模式** — 点击 Header 📋 按钮在新标签页打开完整管理界面：
  - 左侧边栏：所有会话列表，自动根据名称匹配 emoji（吉他🎸、英语📚、编程💻等），点击即切换
  - 右侧详情区：显示会话名称、标签页数、保存时间，以及每个标签页的图标、标题、URL，可单独「打开」某个标签页
  - 顶部操作栏：全局搜索、导入、导出、新建会话
  - 每个会话支持：恢复全部、分享、删除、重命名

### v1.2.0
- **主题切换** — 设置面板（⚙️ 图标）提供三套主题：🌙 深色 / ☀️ 浅色 / 🌿 护眼绿，点击即时切换
- **自定义背景颜色** — 颜色选择器 + 透明度滑块（0–100%），半透明效果让背景色透过界面
- **本地图片背景** — 选择本地任意图片作为背景，独立透明度控制，图片预览 + 一键移除
- **分享会话** — 每张会话卡点击 🔗 图标，生成「分享码」（Base64 编码），发给对方后一键导入还原全部标签页
- **导入会话** — Header「导入」按钮，粘贴分享码即可将他人会话恢复为本地新会话

### v1.1.0
- **编辑会话名称** — 点击卡片右上角铅笔图标，直接内联编辑名称，回车确认，Esc 取消
- **导出 JSON 备份** — 点击搜索栏旁「⬇ 导出」按钮，将所有会话导出为带日期的 JSON 文件，方便备份或迁移

### v1.0.0（初始版本）
- **保存当前标签页** — 点击插件图标，一键保存当前窗口所有打开的标签页
- **自定义命名** — 为每次会话起有意义的名字（如「学习雅思」「练吉他」「LeetCode 周赛」）
- **选择性保存** — 可勾选/取消勾选任意标签页，只保存需要的部分
- **恢复会话** — 点击「恢复会话」在新窗口中原封不动还原所有标签页
- **搜索会话** — 支持按名称快速搜索已保存的会话
- **删除会话** — 删除前有确认弹窗，防止误操作
- **暗色 UI** — 精心设计的深色主题界面，图标、URL 一目了然

## 安装方法（开发者模式）

1. 打开 Chrome，访问 `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本项目根目录（包含 `manifest.json` 的文件夹）

## 项目结构

```
webpage manager/
├── manifest.json          # 插件配置文件（Manifest V3）
├── assets/
│   └── icons/             # 插件图标（16/32/48/128px）
├── src/
│   ├── popup/
│   │   ├── popup.html     # 弹窗 UI 结构
│   │   ├── popup.css      # 弹窗样式（暗色主题）
│   │   └── popup.js       # 弹窗交互逻辑
│   └── background/
│       └── background.js  # Service Worker（标签页查询、窗口恢复）
└── README.md
```

## 数据存储

会话数据存储在浏览器本地 `chrome.storage.local`，不上传到任何服务器，完全离线可用。
